# Bruchmission 7 HS

Interaktives Lernspiel zum Bruchrechnen für Jahrgang 7.

## Veröffentlichung mit GitHub Pages

1. Im Repository `Settings` öffnen.
2. Links `Pages` wählen.
3. Unter `Build and deployment` bei `Source` → `Deploy from a branch`.
4. Branch `main` und Ordner `/(root)` auswählen.
5. `Save` anklicken.

Danach ist das Lernspiel unter dieser Adresse erreichbar:

https://vs-prog73.github.io/bruchmission-7hs/

## Einsatz in IServ

Den obigen Link in die Beschreibung einer IServ-Aufgabe einfügen. Das Arbeitsheft als PDF separat als Anhang in IServ bereitstellen.

Hinweis: Für Teamnamen bitte Fantasienamen verwenden.
